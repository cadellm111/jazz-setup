# Honda Jazz / Fit GD3 — track suspension setup

A single-page, print-friendly setup guide for a first-generation Honda Fit/Jazz (GD1/GD3) used on track.

Covers: diagnosing a corner-exit hop, wheel-rate and ride-frequency maths, droop travel and bump-stop
procedure, damper tuning order for rebound-only coilovers, alignment targets, spring part numbers,
and a test-day sequence.

**Read it:** https://cadellm111.github.io/jazz-setup/

**Alt link (renders straight from the repo):** https://raw.githack.com/cadellm111/jazz-setup/main/index.html

Sources cited in the page: Honed Developments (GD3 suspension recipe), MaXpeedingRods (T6 GD1/GD3
specifications), Coilovers.com (bump stops on lowered cars), Gutentight Racing (coilover travel and
preload).

Corner masses and motion ratios used in the frequency table are estimates — the page says so and
explains how to measure your own.
